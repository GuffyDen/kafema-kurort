# Цель

Сохранить клиентский интерфейс как цельное мобильное приложение, не создавая отдельную архитектуру и не ломая desktop или планшетные рабочие экраны.

# Применять

- При изменении `/`, нижней навигации, карточек, корзины, checkout и модалок.
- При исправлении overflow, sticky/fixed, клавиатуры и touch-проблем.
- При проверке mobile-first макета или утвержденного концепта.

# Не применять

- Для server-only или iiko-задач.
- Для desktop-only админки без мобильного влияния.
- Для изменения `/bar`, кроме явно затронутой планшетной адаптации.

# Порядок действий

1. Найти текущие responsive constraints и не менять визуальный язык без запроса.
2. Проверить ширины 320, 375/390 и 430 px; при затронутом `/bar` также iPad.
3. Пройти сценарий одной рукой: открыть товар, выбрать модификаторы, добавить, открыть корзину, оформить.
4. Проверить экранную клавиатуру, scroll locking, sticky/fixed и safe-area.
5. Проверить длинные данные и отсутствие изображения.
6. Сверить desktop, чтобы мобильная правка не дала регрессию.
7. Применить `tablo-interaction-states` и `tablo-regression-check`.

# Чек-лист

- [ ] Нет горизонтального overflow от 320 px.
- [ ] Нижняя навигация и основной CTA доступны и не перекрывают контент.
- [ ] Sticky-корзина не прыгает и не дублируется.
- [ ] Модалки помещаются по высоте и прокручиваются внутри.
- [ ] Клавиатура не скрывает активное поле и submit.
- [ ] Touch-цели достаточно крупные; disabled читаем.
- [ ] Длинные названия, цены и описания не ломают сетку.
- [ ] Карточка без изображения сохраняет размер.
- [ ] «Нет в наличии» заметно, но карточка остается на месте.
- [ ] Safe-area учтен сверху и снизу.

# Правила Tablo

- Клиентская витрина остается под брендом Кафемы для пилота.
- Не делать адаптацию через отдельный несвязанный mobile tree.
- Не менять desktop и `/bar` без необходимости.
- Утвержденный макет важнее новых дизайнерских идей.

# Итоговый отчет

Перечислить проверенные viewport, сценарии touch/keyboard/scroll, найденные overflow или перекрытия, измененные файлы, визуальные доказательства и оставшиеся device-specific риски.
